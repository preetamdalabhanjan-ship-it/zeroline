# Zero-Line Clinic Hub (`preetamdalabhanjan-ship-it/zero-line-pro`)

**Zero-Line Clinic Hub** is a cross-platform Progressive Web App (PWA) built with a cohesive dark clinical slate-teal design system (`#090d16`), Gmail authentication, Unique Cloud Patient IDs (`CLD-XXXX`), Front Desk Cash Collection, Doctor Tablet Digital Formulary Search, and a Paid-Only Pharmacy Handover Gate.

## Included Files

- `index.html` / `zero_line_clinic_hub.html`: Self-contained production web app (Front Desk, Doctor EHR, Pharmacy Dispatch, Cloud Directory, SaaS Pricing, About/Services/Contact, Legal & Cookie Compliance).
- `manifest.json` & `sw.js`: Cross-OS Progressive Web App installer & offline cache.
- `robots.txt` & `sitemap.xml`: Search engine indexing and XML sitemap configuration.
- `LICENSE`: Public domain / commercial license.
